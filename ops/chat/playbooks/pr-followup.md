## Playbook: follow up on your PR

Something changed on your PR: a review, a comment or a label.

1. Read the reviews and latest comments in the brief. Answer each point: fix it, or reply on the PR why not.
2. Push fixes to this branch and run the tests locally first.
3. When you've answered a review that asked for changes, put the `review:<reviewer>` label back so they're woken.
4. If nothing on the PR needs you (for example it was only approved), reply IDLE.
